# Sunoプレイヤー連携の試作

対象は「ひと駅ぶんの逃避行」のSuno埋め込みと、[ポートフォリオのテストページ](https://hinatabokkuri-star.github.io/suno-player-test.html)です。

`bridge.user.js` をSunoのiframe内で実行すると、再生状態を `postMessage` でテストページに通知します。テストページから再生、一時停止、シークを操作できます。歌詞の行を選び、配信を聴きながらボタンを押すと、実際の再生時刻がその行に付きます。音声をダウンロード、録音、解析、外部送信する処理はありません。

自分のChrome/Edgeで継続利用する場合は、次のどちらかを選びます。これらの導入は自動では行いません。

- 開発用拡張機能: このフォルダーをローカルに置き、拡張機能の管理画面で開発者モードを有効にし、「パッケージ化されていない拡張機能を読み込む」からこのフォルダーを選ぶ。
- 既にユーザースクリプト管理拡張を利用している場合: `bridge.user.js` を登録する。Sunoのiframeでも動く設定が必要。

対象URLはこの一曲の埋め込みだけです。メッセージはポートフォリオの親フレームからのものだけ受け付けます。Cookie、認証情報、音声データは読み取りません。再生にはブラウザーの自動再生制限が適用されるため、必要に応じてSuno枠内の再生ボタンを一度押してください。

歌詞の時刻はブラウザーのlocalStorageに保存されます。LRC保存ボタンで歌詞と時刻のテキストを取り出せます。未設定の行はLRCに含めません。時刻を付けた行にだけハイライトが追従します。Suno側の音声要素やページ構造が変更された場合は修正が必要になることがあります。

この試作はテストページ専用です。既存の楽曲一覧、音楽ファイル、プレイヤーには変更を加えていません。
