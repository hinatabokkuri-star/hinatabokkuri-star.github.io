# SteamとPlayStationの所有ゲームとプレイ履歴

データ取得日：2026年10月2日。ファイル作成日：2026年10月18日。

Steamの226項目とPlayStationの378件のトロフィー履歴を、重複をまとめて569項目に整理しています。ツール・テスト版の5項目を除く564タイトルを、新規おすすめの除外元データにできます。原作とリメイク、続編は区別しています。

PSはトロフィー履歴です。未起動の購入作品や現在の利用権は未確認です。PSの機種欄はトロフィーリストの対応機種で、表示された全機種を所有していることを意味しません。SwitchとSwitch 2は対象外です。

ゲーム名は日本語表記と元の表記を併記しています。ページ内検索で探せます。時間が表示されない項目は未プレイとは判定していません。PSの進捗率はサイト表示の重み付きの値です。Pはプラチナ取得を表します。
